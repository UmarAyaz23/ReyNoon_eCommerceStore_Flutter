Your endDrawer widget is throwing errors because you're trying to put a ListView.builder inside a Column without constraining its height, which causes layout overflow issues. In Flutter, ListView tries to take infinite height if not constrained.

✅ Solution: Wrap the ListView.builder in an Expanded or Flexible widget.

Here’s the fixed version of your code:

dart
endDrawer: Drawer(
  child: Container(
    color: Colors.white,
    child: Column(
      children: [
        Padding(

          child: Text(
            "Cart",

              fontSize: 20,
              fontWeight: FontWeight.bold,
              color: Colors.blueGrey,
            ),
          ),
        ),
        SizedBox(height: 20),
        
        // Fix: Wrap ListView.builder with Expanded
        Expanded(
          child: ListView.builder(
            itemCount: cartItems.length,
            itemBuilder: (context, index) {
              return ListTile(
                contentPadding: EdgeInsets.all(5),
                title: Text(
                  cartItems[index],
                  style: TextStyle(
                    fontSize: 16,
                    fontWeight: FontWeight.w300,
                    color: Colors.black,
                  ),
                ),
              );
            },
          ),
        )
      ],
    ),
  ),
)

Why it works:

  • Expanded tells the Column to let the ListView take the remaining vertical space, thus giving it a bounded height.

  • Without this, ListView tries to expand indefinitely, causing a layout error.
